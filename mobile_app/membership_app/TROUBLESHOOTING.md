# 문제 해결 가이드

## 로딩 화면이 계속 돌아가는 경우

### 1. API 서버가 실행 중인지 확인
앱이 API 서버에 연결하려고 하는데 서버가 실행되지 않으면 로딩이 계속됩니다.

**해결 방법:**
1. 프로젝트 루트에서 다음 명령 실행:
   ```bash
   python start_api_server.bat
   ```
   또는
   ```bash
   cd 07_활용
   python api_server.py
   ```

2. 서버가 정상적으로 실행되면 다음과 같은 메시지가 표시됩니다:
   ```
   * Running on http://0.0.0.0:5000
   ```

### 2. 포트 5000이 사용 중인 경우
다른 프로그램이 포트 5000을 사용하고 있을 수 있습니다.

**해결 방법:**
1. 포트 사용 확인:
   ```bash
   netstat -ano | findstr :5000
   ```

2. 사용 중인 프로세스 종료하거나 `api_server.py`에서 포트 번호 변경

### 3. 네트워크 연결 문제
안드로이드 에뮬레이터는 `10.0.2.2`를 사용하여 호스트 머신에 연결합니다.

**확인 사항:**
- 에뮬레이터가 실행 중인지 확인
- `mobile_app/membership_app/lib/services/api_service.dart`의 `baseUrl` 확인:
  ```dart
  static const String baseUrl = 'http://10.0.2.2:5000/api';
  ```

### 4. 에러 메시지 확인
앱에서 에러 메시지가 표시되면:
- 에러 내용을 확인
- API 서버 로그 확인
- 네트워크 연결 상태 확인

### 5. 앱 재시작
1. 앱 완전 종료
2. API 서버 실행 확인
3. 앱 다시 실행

## 일반적인 문제

### 데이터베이스 파일이 없는 경우
`membership.db` 파일이 없으면 자동으로 생성됩니다. 
첫 실행 시 빈 데이터베이스로 시작됩니다.

### 모듈 import 오류
Python 경로 문제가 있을 수 있습니다. 
`07_활용/api_server.py`가 프로젝트 루트에서 실행되는지 확인하세요.
